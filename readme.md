# Interactive web pages
There are standalone, browser-based versions of the practicals, published via [GitHub Pages](https://cropxr.github.io/EduXR/).



## Repo layout
- `docs/` — the published site: one self-contained HTML page per practical, plus a
  generated answer model for each, plus the `.js` files holding their datasets.
- `tools/` — the scripts that generate the answer models and the dataset files.
- `data/` — the raw GO and transcriptomics inputs those scripts prune down.
